Operating view

What this platform is supposed to become

Preferred foundation

Python API first

FastAPI is the preferred initial framework because it fits the learning, typed API, Jinja and Docker goals. The contracts and controls remain authoritative if another compatible Python ASGI framework is selected.

Source control

GitHub remains authoritative

AI and humans work through branches, reviewable changes and pull requests. Production code is never silently edited.

AI control

Plain English becomes a visible plan

Normal-language requests are classified, scoped and reviewed before approved APIs, MCP tools, sandboxes or GitHub actions are used.

Access

Real protection at every layer

Cloudflare Access, server sessions, capabilities, record ownership, approvals, audit logs and environment separation replace browser-only gates.
