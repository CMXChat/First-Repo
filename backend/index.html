Operating view

What this backend is supposed to become

Foundation

One FastAPI application first

Existing pages can remain static or move into Jinja templates over time. The first objective is a secure Python-capable foundation, not a second frontend stack.

Source control

GitHub remains authoritative

Development occurs in branches. Approved changes reach staging first. Production requires a deliberate approval step.

Access

Real protection at the edge and server

Cloudflare Access confirms identity before traffic reaches the application. FastAPI still validates sessions, roles and ownership.

Expansion

Tools connect only when useful

Some pages should stay browser-only. Server APIs are added where persistence, controlled integrations, file processing or automation create real value.
