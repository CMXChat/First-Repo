show_system_path()

1. GitHub
Stores the source code, documentation and approved configuration.

2. Development branch
Changes happen in an isolated branch through Codespaces or a Dev Container.

3. Staging
The real page and backend behavior are tested before production.

4. Production approval
An authorized person reviews and approves the release.

5. Linux server and Docker
The application runs in a repeatable server environment.

6. FastAPI
Serves pages and receives requests from the HTML frontend.

7. PostgreSQL
Stores users, projects, records, history and other persistent data.

8. Cloudflare Tunnel and Access
Protects the origin and controls who can reach private tools.

list_technology_layers()

HTML controls page structure.

frontend.js

document.querySelector("#url-form").addEventListener("submit", async (event) => {
  event.preventDefault();

  const url = document.querySelector("#target-url").value;

  const response = await fetch("/api/url/analyze", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ url })
  });

  const result = await response.json();
  document.querySelector("#result").textContent = JSON.stringify(result, null, 2);
});

app.py

from fastapi import FastAPI
from pydantic import BaseModel, HttpUrl

app = FastAPI()

class UrlRequest(BaseModel):
    url: HttpUrl

@app.post("/api/url/analyze")
def analyze_url(request: UrlRequest):
    return {
        "url": str(request.url),
        "status": "accepted",
        "next_step": "run approved inspection checks"
    }

The HTML collects the value. JavaScript transports it. FastAPI validates it. Python performs the work. JSON carries the result back.

Where does PostgreSQL enter?
Add PostgreSQL when information must be saved, searched later, connected to a user or project, or preserved as history. A temporary calculation may not need a database. A saved investigation, report, permission or project usually does.
Where should API keys and passwords go?
They stay on the server in environment variables or a secret manager. They never belong inside public HTML or browser JavaScript because browser code can be inspected.

explain_ai_layer()

AI is an optional reasoning layer. Python remains responsible for access checks, approved context, tool permissions, input validation, logging and final action boundaries.

operator request
  -> FastAPI authorization
  -> Python selects approved context
  -> optional retrieval from CMX records
  -> AI model receives limited input
  -> structured response returns to Python
  -> Python validates the response
  -> page shows the result

Useful AI tasks: summarization, classification, extraction, drafting from verified records, search assistance, report generation and natural-language control of approved tools.

MCP later: MCP can expose narrowly defined tools such as repository search, branch creation or approved service access. Read permissions and write permissions should stay separate.
