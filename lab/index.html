What the labels mean

Current frontend truth, deliberately separated from production backend truth.

LIVE

Existing production-facing surface. This label does not imply every future Continuum capability is deployed.

WIRED / PROVING

Frontend uses or models real protected contracts, but live acceptance or deployment may still be pending.

LAB

Experiment or product prototype. Useful for learning and interaction design; not production execution truth.

NEXT

Planned proving surface. Visible here so the Lab map shows where today's work is heading without pretending it exists.
