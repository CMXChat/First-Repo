Evidence handling notes

      
Integrity: The SHA-256 value identifies the exact imported bytes. Keep the original file unchanged and record where it came from.

      

      
Interpretation: Metadata can be removed, rewritten, malformed, inherited from software, or copied between files. Treat it as an observation that requires corroboration.

      

      
Export: The JSON export contains metadata and warnings, not the source file itself. File contents are excluded except for the bounded text preview already visible on screen.
