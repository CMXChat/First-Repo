Lesson 03 · How the sides talk

An HTTP request is just a structured message

The frontend does not need its own secret backend API. It calls the API exposed by FastAPI. HTTP is the agreed way the message travels, and an endpoint is one specific backend address that knows how to handle a type of request.

Lesson 05 · Proving who is making the request

Why you do not log in again on every click

After the backend verifies your credentials, later protected requests need a safer form of proof that says the request belongs to an authenticated user. Tokens and sessions are two common mental models for that continuing proof.

Token model

1 · LoginYou submit credentials

The frontend sends the login request over HTTPS.

2 · VerifyBackend checks them

FastAPI verifies the account using protected backend logic.

3 · Issue proofA token is created

The app receives proof that represents the authenticated session or identity.

4 · Use proofProtected calls include it

Later API requests can be accepted only after the backend verifies the proof.

A token is a piece of proof the client can present with later requests. The server verifies that proof before allowing protected actions. The exact storage and security design matters, so treat “token” as the concept first, not permission to put secrets anywhere in frontend code.

Lesson 07 · The pieces around the request

The other words in your environment

Once the request flow makes sense, the supporting tools stop looking random. Each one helps the same application stay organized, repeatable, safer to change, or easier for the frontend and backend to coordinate.

API

Generated API client

Frontend helpers generated from the backend API description so React code can call endpoints with the expected paths and data shapes.

Why frontend/src/client matters

Instead of hand-writing every request shape, the generated client gives TypeScript code a cleaner, typed bridge to the FastAPI API. The endpoints still live in the backend.

↗

TanStack Router

Frontend routing decides which React view should appear for a browser URL without turning every page change into a traditional full reload.

Simple version

It is the frontend map between URLs and screens. It is different from a FastAPI route, which maps an HTTP request to backend Python code.

Q

TanStack Query

Helps the frontend manage server data: loading it, caching it, refreshing it, and keeping UI state connected to API results.

Simple version

React displays the interface. Query helps with the part where that interface depends on data coming from the backend.

DB+

Migrations

Controlled, repeatable changes to the database structure as the app evolves.

Example

If an Item table needs a new priority column, a migration records the schema change so environments can apply the same change deliberately.

BOX

Docker

Packages the application and its runtime setup into containers so the same services can run more consistently across machines and environments.

Simple version

Docker is not your backend language. Python is still Python. Docker helps package and run the pieces with a defined environment around them.

PKG

Dependencies

Libraries your project relies on, such as FastAPI on the backend or React-related packages on the frontend.

Why manage them carefully?

Adding a dependency means adding code your project now relies on. The environment should know why it exists, which version is used, and whether it belongs in the project.

Two local addresses

localhost just means your own machine

During development, the frontend can run at an address such as http://localhost:5173 while the FastAPI backend runs on another local port. They are two local services talking over HTTP, even though both are on the same computer.

API

A defined way for software to ask another piece of software for data or actions. In this app, the frontend calls the backend API.

Endpoint

One specific backend method + path that handles a type of HTTP request, such as GET /api/items.

HTTP request

A structured message sent to a web server. It can include a method, path, headers, and body.

HTTP response

The structured answer the backend sends back, including a status code and usually data.

JSON

A common text format for structured data, such as {"title":"Study"}.

Frontend

The part running in the browser that the user sees and interacts with. Here it uses React and TypeScript.

Backend

Server-side code that owns application rules, protected logic, API endpoints, and database access. Here it uses FastAPI and Python.

React

A JavaScript library for building interactive user interfaces from reusable components and state.

TypeScript

JavaScript with a type system that helps catch many mistakes earlier and describes expected data shapes.

Component

A reusable piece of React UI, such as a button, card, form, or entire page section.

State

Information the frontend is currently keeping track of, such as which tab is selected or what data has loaded.

FastAPI

A Python web framework used here to expose backend endpoints, validate data, run backend logic, and return responses.

Route

A mapping. In frontend routing it maps a URL to a screen. In FastAPI it maps an HTTP method + path to backend Python code.

PostgreSQL

A relational database used for durable structured application data.

Table

A structured database collection with columns and rows, similar to a highly controlled data sheet.

Database model

A code-level representation of application data and its structure so backend code can work with records consistently.

Migration

A recorded database schema change, such as adding a column or creating a new table.

Authentication

The process of proving who a user is and carrying safe proof into later protected requests.

Authorization

The decision about what an authenticated user is allowed to see or do.

Token

A form of authentication proof that can be verified on later requests. The security details depend on the implementation.

Session

A way to maintain signed-in state across requests so the user does not resend credentials every time.

Generated API client

Frontend code generated from the API definition so TypeScript can call backend endpoints with known request and response shapes.

OpenAPI

A machine-readable description of an API. FastAPI can generate this description, which can then help generate a frontend client.

TanStack Router

A frontend routing library that helps map browser URLs to React views.

TanStack Query

A frontend library for managing server data, loading states, caching, and refresh behavior.

Tailwind

A CSS utility framework that provides small classes for styling interface elements and layouts.

shadcn/ui

Docker

A container system used to package and run application services with a defined environment.

Dependency

An external library or package the project relies on.

localhost

A hostname that points back to your own computer. Development servers often run on localhost with different ports.

Port

A numbered network doorway on a machine. Different local services can listen on different ports.

Environment variable

A configuration value supplied outside normal source code, often used for environment-specific settings and secrets.

The bird's-eye view

If you can explain this paragraph, the stack is starting to belong to you

You open a React + TypeScript frontend in the browser. When the interface needs backend data or an action, frontend code calls a generated API client, which sends an HTTP request to a FastAPI endpoint. The Python backend validates the request, checks authentication and permissions where needed, applies application logic, talks to PostgreSQL for durable data, and sends an HTTP response back. React then uses that result to update what you see.
