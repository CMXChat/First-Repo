Interactive flow

Follow one request

Imagine you press a button that says Open my profile. The request moves through these pieces. Tap each one to see its job.

Browser: this is where the person sees and uses the app. The browser itself does not know your database. It displays the frontend and lets JavaScript send requests when you click something.

The first mental model

Three jobs to remember

You do not need to memorize framework names first. Start with the jobs. The names become much easier once you know why each piece exists.

Frontend

Shows things and listens to you

Pages, buttons, forms, menus, loading states, and the JavaScript that asks the backend for something.

Backend

Checks and decides

Python receives the request, checks what is allowed, runs the app logic, talks to the database, and prepares a response.

Database

Stores what must survive

Accounts, records, settings, and other durable information live here so they still exist after the request is finished.
