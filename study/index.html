Developer-soup translator

Search the exact word that broke the sentence

If one word is fuzzy, stop there. You should never have to understand five new words just to define the first one.

Frontend

The visible part of the app running in the browser.

Backend

Private server-side code that handles app rules, processing and protected data access.

React

A JavaScript library used to organize interactive frontend interfaces.

Component

A reusable piece of frontend interface, such as a Weather card or button.

API

A defined way for one piece of software to ask another for data or an action.

Endpoint

One specific backend API door for a type of request.

HTTP request

A structured message sent from the frontend to the backend.

HTTP response

The backend's structured answer to a request.

Python

The programming language used for backend logic in this environment.

FastAPI

A Python framework that helps build API endpoints and handle web requests.

Framework

Reusable code and conventions that handle common plumbing so developers can focus on app-specific work.

PostgreSQL

A relational database used to store durable structured records.

Table

An organized database structure made of rows and columns.

ID

A value that uniquely identifies a record and can help connect related records.

Authentication

Proving who a user is.

Authorization

Checking what an authenticated user is allowed to see or do.

Password hash

A one-way representation used to verify a password without storing the readable password itself.

Token

One possible form of proof that later requests can use after login.

Session

A continuing logged-in state that helps a server recognize a browser across requests.

JSON

A common text format for structured data passed between software.
