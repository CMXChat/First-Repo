Two full-stack pictures worth keeping in your head

The exact feature can change. The architecture pattern stays useful.

Spaces

You tap something in the briefing UI. React sends a request. FastAPI routes it to Python. Backend logic checks identity/permission, reads or changes data, may call an AI/tool workflow, then returns data so React updates the screen.

React→HTTP/API→FastAPI→Python→Postgres / tools / AI→React

OSINT tool

You submit a search or case action. The browser sends it to a protected backend endpoint. Python can query approved sources/tools, process evidence, optionally use AI to summarize/classify, store case/report data, and return structured results.

Search UI→POST /search→Python research logic→sources / AI→case DB→results UI
